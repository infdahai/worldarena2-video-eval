## 2. 本轮实现的模型

v11 保留冻结的 Wan2.2-TI2V-5B 与冻结的 `clean-gated-step10` raster parent，在 Wan block 6/16/24 后插入三段双臂控制器：

```text
left action content  -> left persistent slots  -> local visual read/write
right action content -> right persistent slots -> local visual read/write
                              |
                              +-> per-arm EEF head
```

核心合同：

- 左右臂状态永久隔离；
- 每臂四个 action slots：translation / rotation / image motion / gripper；
- 独立 anchor tokenizer 保留每臂绝对起始几何；
- 视觉读写只发生在对应 support tube；
- latent0 与 absent arm 严格置零；
- frozen Wan 与 frozen parent 不接收梯度；
- Stage-A 只训练 tokenizer、state updater、read/write attention、channel gate 和 EEF head；
- 不加载 T5/VAE，不加入 Depth、V-JEPA、GAN、object/coordination branch。

可训练参数总量：`40,244,742`，满足正式 `[40M, 80M]` 合同。

## 9. 架构判断

v11 给出了两个清晰信号：

1. **persistent bimanual controller 的训练机制成立。** 参数更新、显存、状态隔离、EEF 学习均正常。
2. **当前 EEF head/weighted-FM/binding 组合仍不足以建立双向 latent phase 判别。** 特别是 `-1` 只有 8/20，说明模型仍可能将相邻动作内容提前或延后绑定。

这不是继续多跑 400 step 就应自动忽略的失败。按照已批准的实验规则，应先停止并决定下一步是否：

- 把 phase ranking 变成真实训练项，而不是只做 gate；或
- 将 per-interval destination binding 进一步硬化；或
- 放弃当前 Stage-A objective，转向更直接的 final visual trajectory supervision。

在作出新设计前，不建议继续 v11 step500，也不建议解码大批 RGB。
